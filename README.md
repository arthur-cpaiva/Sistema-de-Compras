# Sistema-de-Compras
Desenvolvimento de um sistema web de requisição de compras utilizando HTML, CSS, JavaScript, PHP e MySQL.  O sistema permitirá que setores solicitem materiais, acompanhem o status das requisições e que o usuário 'Compras' registre cotações e anexe orçamentos, encaminhando-os ao gerente para aprovação ou reprovação e escolha do fornecedor. O sistema contará com logins, inserção de textos, imagens e anexos em PDF. 

O usuário 'Solicitante' irá fazer a solicitação do material, especificando o nome, quantidade e alguma observação adicional sobre a necessidade de tal item. O mesmo, poderá inserir alguma imagem ou vídeo para melhor explicação da solicitação. 

Depois da solicitação ser registrada, o usuário 'Compras', começará o processo de cotação. O mesmo, terá que inserir em cada campo, a especificação do material, quantidade solicitada, motivo da requisição (com explicação da necessidade do setor), preço de cada material com o nome de cada fornecedor. Depois, inserir imagens ou PDF dos orçamentos que foram enviados por cada fornecedor. 

Após todo o processo de cotação ter sido realizado, o usuário 'Compras' irá subir essa requisição no sistema.

O usuário 'Gerente', irá analisar em outra página todas as informações da requisição. O mesmo precisará dar somente um aceite ou recusar a requisição. Terá um campo de observação, onde ele poderá inserir algum texto.
